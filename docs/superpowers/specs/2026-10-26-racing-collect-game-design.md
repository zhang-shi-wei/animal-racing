# 休闲收集养成赛车小游戏 · 设计文档

- 日期:2026-10-26
- 状态:待审阅
- 类型:微信小游戏

## 1. 概述

一款以**收集养成为主**的休闲赛车微信小游戏。玩家收集可爱的**动物主题小车**,通过**点按加速**跑关卡竞速赚取资源,用资源**升级性能**、**孵化车蛋**扩充收藏。美术采用**星露谷像素风**,整体节奏轻松、治愈。

## 2. 核心玩法与循环

```
点按加速跑关卡 → 按用时评 1~3 星 → 结算奖励(金币 + 概率掉蛋)
        ↑                                        ↓
   升级车性能(速度/收益↑)                  蛋孵化 → 开出新车(收集)
        ↑                                        ↓
        └──────────── 金币 / 新车都回到循环 ─────────┘
```

一句话:**跑比赛赚金币和蛋 → 金币升级车跑得更快、蛋孵出新车扩充收藏**。

## 3. 美术风格

- 星露谷像素风(复古、田园、治愈)
- 收集对象:**可爱的动物主题小车**——萌系大眼睛 + 动物元素(小猪车、小乌龟车、小鸟车等)

## 4. 技术选型

- **引擎**:Cocos Creator 3.x
- **语言**:TypeScript
- **发布**:微信小游戏(Cocos 一键构建)
- **存档**:本地 `wx.setStorageSync`,纯单机,无后端

## 5. 场景与界面结构

两个 Cocos 场景 + 若干弹层:

**1. 主场景(Home)** —— 小窝/车库大本营
- **车库页**:展示已收集的动物车、选中车辆、进入升级
- **孵化室页**:孵化中的蛋、孵化进度、开蛋
- **图鉴页**:查看已收集 / 未收集的车
- 顶部常驻金币余额;三页用 Tab 切换

**2. 比赛场景(Race)** —— 关卡竞速
- 赛道 + 动物车(像素背景滚动)
- 点按加速 HUD(速度 / 用时 / 体力 / 进度)
- 结算弹层(1~3 星 + 奖励)

## 6. 核心系统

| 系统 | 职责 |
|------|------|
| SaveSystem | 统一存档读写,数据变动后落盘 |
| CarLibrary | 静态车辆图鉴配置(MVP 3~5 种) |
| UpgradeSystem | 消耗金币升级车,提升速度 / 收益 |
| HatchSystem | 蛋的获得、孵化倒计时、开蛋抽车 |
| RaceSystem | 加载关卡、点按加速、体力与障碍、计时评星、结算 |
| TraitSystem | 特性加成管道(见第 10 节) |

## 7. 数据模型

```ts
interface Car {
  id: string;              // "pig"
  name: string;            // "小猪车"
  animal: string;          // 动物类型
  rarity: 'common'|'rare'|'epic';
  baseSpeed: number;       // 最大速度上限(升级提升)
  baseAccel: number;       // 加速度(按住时速度上升速率)
  level: number;           // 当前等级(升级维度)
  owned: boolean;          // 是否拥有
  habitat: 'land'|'water'|'sky';   // 场景亲和(隐藏特性)
  // —— 预留字段(本期留空,后续启用)——
  circadian?: 'diurnal'|'nocturnal'|'crepuscular';
  satiety?: number;        // 当前饱腹度 0~100
}

interface Egg {
  id: string;
  rarity: 'common'|'rare';
  hatchDuration: number;   // 孵化时长(秒,现实时间)
  startTime: number;       // 开始孵化时间戳
  resultCarId: string;     // 孵化结果车
}

interface Level {
  id: string;
  name: string;
  scene: 'land'|'water'|'sky';   // 关卡场景
  distance: number;              // 赛道长度
  starTime: [number, number];    // [三星阈值, 两星阈值](秒,越短越好)
  rewards: { coins: number; eggDropRate: number };
}

interface PlayerProgress {
  coins: number;
  currentCarId: string;
  ownedCars: Car[];
  eggs: Egg[];
  unlockedLevel: number;
}
```

**关键点**:图鉴配置(CarLibrary)与玩家数据(ownedCars)分离;稀有度决定基础属性与开出概率。

## 8. 场景系统与隐藏特性

### 场景类型

关卡有 3 种场景,对应 3 种像素背景与赛道元素:
- **land(地面)**:草原 / 公路
- **water(水域)**:河流 / 海洋
- **sky(天空)**:云端

### 隐藏特性(场景亲和)

- 每辆车有 `habitat`,当 `车.habitat == 关卡.scene` 时,比赛获得 **+20% 速度加成**(配置项,可调)。
- 这是动物类型自带的被动特性,**不通过升级获得**。
- **完全隐藏,不展示给玩家**:图鉴 / 选车界面不渲染 `habitat`,玩家通过实际比赛自己摸索发现。
- 战略意义:收集不同栖息地的车,以应对不同场景的关卡。

MVP 车辆覆盖三类栖息地:

| 车 | 动物 | habitat |
|----|------|---------|
| 小猪车 | 猪 | land |
| 小乌龟车 | 龟 | water |
| 小鸟车 | 鸟 | sky |
| (可选) 小鸡车 | 鸡 | land |
| (可选) 小鱼车 | 鱼 | water |

## 9. 比赛玩法

### 操作(点按加速)

- 按住屏幕 → 加速(速度按 `baseAccel` 上升,至该车最大速度)
- 松手 → 减速
- 车始终向前跑(横向卷轴赛道)

### 松手理由(体力 + 障碍)

- **体力/油量**:按住加速消耗体力,松手回体力;体力见底只能慢速滑行。
- **减速障碍**:赛道上分布水坑、石头、泥地等障碍,撞上大幅减速损失时间,玩家提前松手减速规避。

### 星级判定

- 到达终点用时 T,对比关卡阈值:`T ≤ 三星阈值` → 三星;`≤ 两星阈值` → 两星;否则一星。
- 星级越高,金币越多、掉蛋率越高。

### 升级维度

- 每辆车有 `level`(1~N),消耗金币升级,随等级递增。
- 每级提升:最大速度(提升 `baseSpeed`,帮助拿高星)+ 收益(结算金币系数)。
- 收益系数由 `level` 推导:结算金币 = 关卡基础金币 × (1 + (level - 1) × 5%)。

## 10. 特性加成系统(可扩展)

所有"速度加成"统一走一条管道,便于后续扩展,不硬编码在比赛逻辑里。

```ts
interface CarTrait {
  id: string;
  getSpeedMultiplier(ctx: RaceContext): number;
}
// 最终速度 = baseSpeed × 所有 trait 系数相乘
```

| 特性 | 状态 | 逻辑 |
|------|------|------|
| 场景亲和(habitat) | ✅ 本期实现 | habitat 匹配 → ×1.2 |
| 喂食/饱腹度(satiety) | 🔜 预留接口 | 倒 U 形:饿→慢,吃饱→快,吃撑→慢 |
| 作息(circadian) | 🔜 预留接口 | 昼行动物白天快,夜行动物夜间快 |

**未来加特性只需两步**:给 `Car` 补字段 + 实现一个 `CarTrait` 挂进管道,核心比赛 / 结算逻辑不动。

### 预留特性的未来逻辑(本期不做)

- **喂食**:车有饱腹度,随时间下降;喂食物提升。加成倒 U 形——饥饿(<30)减速、适中(50~80)加速、吃撑(>90)减速。需引入"食物"资源。
- **作息**:车有作息类型,按时间判昼夜,昼行动物 6:00–18:00 加速,夜行动物 18:00–6:00 加速(现实时间或游戏内时间,后续确定)。

## 11. 存档方案

- 本地存档:`wx.setStorageSync('save', JSON.stringify(progress))`
- 结算、升级、孵蛋后即时落盘;启动时读取,无存档则初始化新档。
- 孵化用现实时间(时间戳),退出游戏倒计时仍在走。
